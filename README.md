# Fuel Prices Dashboard

## Project Overview

The Fuel Prices Dashboard is an interactive Power BI project designed to analyze and visualize fuel prices across different countries. It provides insights into petrol, diesel, LPG, and Brent crude oil prices, helping users compare fuel costs, monitor trends, and understand global pricing patterns.

## Objectives

- Analyze global fuel prices.
- Compare petrol, diesel, and LPG prices by country.
- Track fuel price trends over time.
- Monitor Brent crude oil prices.
- Support data-driven decision-making through interactive visualizations.

## Tools and Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Interactive Dashboards

## Dashboard Features

- KPI cards displaying key fuel price metrics
- Country-wise fuel price comparison
- Petrol price analysis
- Diesel price analysis
- LPG price analysis
- Brent crude oil monitoring
- Interactive map visualization
- Trend analysis by year
- Detailed data table for country-level information

## Dataset

The dataset includes information such as:

- Country
- Date
- Petrol Price (USD/Liter)
- Diesel Price (USD/Liter)
- LPG Price (USD/Liter)
- Brent Crude Oil Price (USD)
- Tax Percentage

## Key Insights

- Compare fuel prices across different countries.
- Identify countries with the highest and lowest fuel prices.
- Analyze yearly changes in fuel pricing.
- Understand the relationship between crude oil prices and fuel costs.
- Monitor tax percentages affecting fuel prices.

## Business Benefits

- Supports fuel market analysis.
- Enables comparison of international fuel prices.
- Assists in identifying pricing trends.
- Helps policymakers and businesses make informed decisions.
- Provides a centralized dashboard for fuel price monitoring.
